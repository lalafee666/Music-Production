# Music Production


This project was developed as part of a university module at Hochschule Mittweida.

The goal of the project was to compose, record, edit, mix, and master a complete music production using Ableton Live 12 and external audio hardware.


## Project Work
- Composition and arrangement in Ableton Live 12
- Recording and integration of external audio hardware
- Editing and processing of audio recordings
- Mixing and mastering of the final production


## Documentation
The project documentation can be found in the `docs` directory.

It includes:

- Project presentation as PDF
- Video presentation of the project
